# Red Hat Advanced Cluster Security (ACS) Policy Repository

This repository contains comprehensive audit checklists, policies, and documentation for Red Hat Advanced Cluster Security (ACS) for Kubernetes environments.

## Contents

- [ACS Audit Checklist](ACS-Audit-Checklist.md) - Comprehensive 200+ item security audit checklist
- [Quick Reference Guide](Quick-Reference.md) - Essential commands and configurations for daily operations
- [Policy Templates](policies/) - Production-ready ACS policy templates for all lifecycle stages
- [Configuration Guidelines](config/) - Detailed setup and hardening guides
- [Report Templates](templates/) - Compliance and security assessment report templates
- [Contributing Guidelines](CONTRIBUTING.md) - How to contribute to this repository

## Overview

Red Hat Advanced Cluster Security (ACS) provides comprehensive security for Kubernetes and OpenShift environments. This repository helps organizations implement, audit, and maintain proper security posture using ACS.

### What's Included

- **200+ Security Checkpoints**: Comprehensive audit checklist covering all ACS security domains
- **Production-Ready Policies**: Template policies for build-time, deploy-time, and runtime security
- **Installation Guides**: Step-by-step setup instructions with security hardening
- **CI/CD Integration**: Examples for GitHub Actions, Jenkins, GitLab CI, and more
- **Compliance Templates**: Report templates for security assessments and audits
- **Quick Reference**: Essential commands and troubleshooting guides

## Quick Start

1. **Assessment**: Review the [ACS Audit Checklist](ACS-Audit-Checklist.md) for comprehensive security evaluation
2. **Daily Operations**: Use the [Quick Reference Guide](Quick-Reference.md) for common tasks and troubleshooting
3. **Policy Implementation**: Deploy security policies from the [policies](policies/) directory
4. **Configuration**: Follow setup guides in the [config](config/) directory for secure installation
5. **Reporting**: Use [report templates](templates/) for compliance documentation
